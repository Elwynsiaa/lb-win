Unofficial repository providing automated native Windows (.exe) binaries for the Ladybird web browser. These weekly builds are compiled directly from the upstream master branch using GitHub Actions.

About Ladybird for Windows

Ladybird is a brand-new, independent web browser built from scratch in C++ and Rust. While official support is currently focused on Linux and macOS, this project automatically builds the experimental Ladybird native Windows port every week.

How to install Ladybird on Windows:

  1. Download the latest Ladybird-Windows-Release.zip from the links above.
  2. Extract the entire folder to your Desktop or Downloads folder.
  3. Make sure you have the Microsoft Visual C++ Redistributable installed.
  4. Run Ladybird.exe inside the extracted bin folder!
